# UIKit Architecture References

- `selection.md`: choose MVP, MVVM, VIPER, Coordinator, Clean Architecture, or
  Reactive overlay from local constraints.
- `mvc-migration.md`: split large UIViewControllers without a big-bang rewrite.
- `mvp.md`: passive View plus Presenter protocol contract.
- `mvvm.md`: UIKit ViewModel boundary and view state rendering.
- `viper.md`: strict View/Interactor/Presenter/Entity/Router separation.
- `coordinator.md`: flow ownership, child coordinators, routers, and deep
  links.
- `clean-architecture.md`: use cases, repositories, and UIKit presentation
  adapters.
- `reactive.md`: Combine/Rx pipelines in Presenter/ViewModel layers.
- `swiftui-interop.md`: UIHostingController, SwiftUI adapters, and migration
  ownership.
- `implementation-playbooks.md`: fuller module shapes, migration paths, and
  review checklist matrices after a pattern has been selected.

Load only the file needed for the current architecture decision.
