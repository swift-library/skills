# Accessibility Examples

Examples are illustrative. Load only the framework file needed for the current
task, and do not let examples override local project constraints.

- `before-after-swiftui.md`: SwiftUI modifier and control transformations.
- `before-after-uikit.md`: UIKit `UIAccessibility` transformations.
- `before-after-appkit.md`: AppKit `NSAccessibility` transformations.
