# Templates

Reusable release engineering templates for `apple-platform-release`.

- `ExportOptions.app-store.plist`: App Store Connect export method for
  `xcodebuild -exportArchive`.
- `ExportOptions.developer-id.plist`: Developer ID export method for macOS
  distribution outside the Mac App Store.
- `release-checklist.md`: compact release engineering handoff checklist.
