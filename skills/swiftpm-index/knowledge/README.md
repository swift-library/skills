# Knowledge

This directory holds curated, reviewable hints for `swiftpm-index`. Generated
or fetched source lists never update these files automatically.

Read only the file needed for the active task:

- `replacement-patterns.md`: common custom-wheel to library mappings used as
  discovery prompts.
- `apple-package-hints.md`: curated Apple-authored package hints with review
  stance and cautions.
- `swiftlang-package-hints.md`: curated swiftlang package hints with review
  stance and cautions.
- `official-source-index.md`: official source categories and authority for the
  `official` profile.
- `non-adoption-patterns.md`: reasons to prefer Reference or Keep custom over
  adoption.
