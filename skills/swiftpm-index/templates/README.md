# Templates

This directory holds report shapes for `swiftpm-index` output.

- `package-audit-report.md`: full package audit report in the `SKILL.md`
  output order.
- `package-candidate-card.md`: one candidate's evidence, fit, and
  recommendation.
- `migration-recommendation.md`: one Adopt / Wrap / Reference / Keep custom
  recommendation with its migration seam.
