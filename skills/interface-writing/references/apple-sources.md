# Apple Interface Writing Sources

Use this file when official Apple writing guidance, terminology, or freshness
matters. Do not load it for routine rewrites unless the task needs platform
basis or style-guide confirmation.

## Human Interface Guidelines

- [Writing](https://developer.apple.com/design/human-interface-guidelines/writing/)
- [Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts)
- [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)

## Style Guide

- [Apple Style Guide](https://support.apple.com/guide/applestyleguide/welcome/web)

- [Writing Great Accessibility Labels](https://developer.apple.com/videos/play/wwdc2019/254/)
- [Writing for interfaces](https://developer.apple.com/videos/play/wwdc2022/10037/)

- [Make a big impact with small writing changes](https://developer.apple.com/videos/play/wwdc2025/404/)

## Use

- Use HIG Writing for general interface wording, hierarchy, clarity, and tone.
- Use HIG Alerts for alert, dialog, confirmation, and destructive-action copy.
- Use HIG Accessibility and the accessibility-label session when labels need
  platform-specific precision.
- Use the UX writing sessions for voice, tone, personality, and small-copy
  review.
- Use the Apple Style Guide for Apple terminology, capitalization, spelling,
  inclusive language, and international style.
