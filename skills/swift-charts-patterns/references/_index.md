# Reference Index

Use this index only when `SKILL.md` routing is not enough.

## Swift Charts

- `charts.md`: `Chart`, `Chart3D`, marks, axes, scales, legends, styling,
  `ChartProxy`, selection, gestures, scrolling, plot APIs, and modifier scope.
- `charts-accessibility.md`: VoiceOver, Audio Graph,
  `AXChartDescriptorRepresentable`, fallback strategies, WWDC sessions, and
  version checklist.

## Symptom Routing

- Missing chart types or unresolved symbols: `charts.md`.
- Wrong mark, axis, scale, legend, styling, or annotation behavior: `charts.md`.
- Selection, `ChartProxy`, overlay, gesture, or scrolling issue: `charts.md`.
- `Chart3D`, `SurfacePlot`, Z-axis, camera, or pose issue: `charts.md`.
- VoiceOver, Audio Graph, descriptive labels, or custom accessibility
  descriptor issue: `charts-accessibility.md`.
- Deployment-target fallback or version checklist issue:
  `charts-accessibility.md`.
