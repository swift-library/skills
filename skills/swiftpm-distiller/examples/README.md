# SwiftPM Distiller Examples

Use these examples only to calibrate output shape. They are not templates to
copy verbatim.

- `library-only-distillation.md`: small library package with README/tests as
  the main usage evidence.
- `tool-or-macro-distillation.md`: package with executable, plugin, macro,
  result-builder, or command-style surfaces.
- `framework-augmentation-distillation.md`: package that improves a host
  framework workflow, where the trigger should lead with the host task before
  package symbols.
