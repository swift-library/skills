# Architecture

This directory indexes current architecture rules for the `swift-skills`
collection.

## Index

- `skill-authoring.md`: required skill structure, progressive disclosure model,
  trigger-contract expectations, optional `agents/` metadata, and validation
  checklist.

## Reading Rule

Read architecture files only when creating, changing, or reviewing collection
structure. For normal skill use, start with the target skill's `SKILL.md`.
